Hospital Appointment Manager (HTML + CSS + JavaScript + Java)

Files:
- index.html
- Server.java
- Server.class (generated by Java; do not create manually)

Requirements:
- JDK 11 or newer (JDK 17 or 21 recommended)

Run:
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Compile:
   javac Server.java
4. Start:
   java Server
5. Open http://localhost:8080 in your browser.

Features:
- Book appointments
- View appointment history
- Cancel appointments
- Reschedule appointments
- Prevent two active appointments for the same doctor/date/time

Notes:
- Appointment data is stored in memory and is cleared when the Java server stops.
- Doctor hours and available times are demo data, not real hospital availability.
- This is a learning project, not for real patient data or medical use.
